Как установить

1. Опубликуй сайт по HTTPS

Для установки на iPhone веб-приложение должно открываться по защищённой ссылке. Например, через GitHub Pages или Netlify.

2. Открой ссылку в Safari

Нажми «Поделиться» → «На экран Домой». Если доступен переключатель веб-приложения, включи его.

3. Добавь виджет

Зажми пустое место на экране «Домой» → «Изменить» → «Добавить виджет». Важно: iOS не позволяет обычной веб-странице создать полноценный интерактивный нативный виджет с произвольным обновлением. Установка как веб-приложения сама по себе этого не гарантирует.

Сейчас это рабочий адаптивный прототип. Для постоянной ссылки его нужно разместить на хостинге; я не могу опубликовать его в интернете прямо из этого чата.
